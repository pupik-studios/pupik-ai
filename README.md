# Pupik AI

Локальный чат-ИИ от **Владимирова Роберта Павловича** (Pupik Studios).

Не облачная LLM: интенты, задачи, картинки, файлы, режим агента с саб-агентами-критиками.

## Запуск

```bash
cd ai   # или корень этого репозитория
python3 -m http.server 8770
```

Открой http://127.0.0.1:8770/

Или через GitHub Pages / любой статический хостинг — достаточно открыть `index.html` по HTTP.

## Режим агента

- Кнопка **агент** — включает постоянный режим: каждый ответ проходит через **3 саб-агента-критика** (строгость / польза / тон), оценка **/10** и правка черновика.
- Разовая просьба: «запусти критиков» / «режим агента» — критики на один ответ.

## Возможности

- Чат RU/EN + исправление раскладки
- Задачи «как скачать / установить…»
- Картинки и коллаж с фото («сделай меня с роналду»)
- Файлы 📎
- Несколько чатов, сброс, удаление
